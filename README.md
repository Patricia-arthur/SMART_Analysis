# SMART Analysis

## Project Description

This project focuses on evaluating recurrent malaria following treatment with artemisinin-based combination therapies (ACTs) among children aged 6 months to 10 years in Ghana.

The analysis compares the efficacy of Artemether–Lumefantrine (AL) and Artesunate–Pyronaridine (AP) in treating uncomplicated malaria over a 42-day follow-up period.

The project uses R for data preparation, cleaning, statistical analysis and visualisation. Key analyses include treatment outcomes, parasite clearance, recurrent parasitaemia and Kaplan–Meier survival analysis, with PCR correction to distinguish recrudescence from reinfection.

The repository contains the R scripts and analytical reports developed as part of the project. Research datasets are excluded to maintain data confidentiality.
